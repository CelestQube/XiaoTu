# 小途 · 前端设计与扩展指南

## 设计定位

本版面向希望用一句自然语言开始规划的个人旅行者。页面首要工作是降低“开口”的成本，不是展示一屏功能按钮。

视觉方向：山海间的一张旅行桌面。海盐白打底，墨绿文字、浅天空蓝、松叶绿和少量日光黄；自然成为舒缓背景，不干扰聊天。独特处理是右侧拱形山海明信片和中心书写感标题。使用系统中文字体，不依赖外网下载。

## 页面及交互

1. 与小途聊聊：左侧导航，中央对话，右侧旅行概览；窄屏隐藏概览，手机底部导航。空态展示暂定 Logo 和向左自动滚动的功能提示。点击只填入输入栏，不自动发送。支持暂停、键盘焦点暂停及减少动态效果设置。
2. 我的行程：分日时间轴、地点参考、天气/路线（仅在接口返回时显示），每项安排可以展开编辑。日历导出需明确日期及复选框确认，下载 ICS，不宣称已写入线上日历。
3. 旅行账本：计划区间和实际记账分开；可调整总预算、增删支出，提示估算上限超预算。区间不含待核实城际票价。
4. 旅行偏好：常居城市、日均预算、交通、兴趣可编辑清除。对话抽取的偏好须经“确认保存”才进入画像。可关闭本次会话的画像使用。
5. 数据与连接：区分演示、服务配置与实际调用结果；展示最新 sources，并提供官方 12306 链接。

输入区约占桌面聊天视窗六分之一至五分之一，受最小可用高度影响。仅键盘输入；无伪装成可用功能的语音或图片按钮。Enter 发送，Shift+Enter 换行，中文输入法组合期间不发送。

## Logo 概念（待用户确认）

按用户指定的 [logo-design skill](https://github.com/kaankiziltug/logo-design-skill) 阅读了主流程、简报、SVG 构造指导。没有安装或执行第三方安装脚本，也没有复制参考品牌 Logo。

简报假设：名称小途，亲和、自然、松弛、清晰，用于网页及未来 App。避免飞机＋定位针的旅游拼贴；Logo 只保留一个概念。

探索清单：叶片留白中的弯路、山峰间的步道、道路回转与起点、风吹开的书页、途中停靠的石头、海浪缺口中的门、t 字路标、“小”字三段旅程、云隙中的路。

选择三份差异明显的原创 SVG：
- A 一叶有途（推荐）：两片弧形间形成道路；自然陪伴感强，后续需检索叶片类商标相似性。
- B 山间留白：山峰与步道的几何关系；小尺寸明确，但户外品类常见。
- C 转个弯：起点与折返道路的抽象图形；结构有力，但偏导航工具。

评审入口 public/logo-concepts.html，提供 64 / 32 / 16 px 与反白预览。应用暂用 A 作可替换原型，不等于用户已批准。保留概念检查点，不提前交付完整 Logo 套件；待确认方向后再制作最终色彩、字标、组合版、App 图标与规范。未做商标查重，不保证可注册。

体量增长后按这些边界拆为 modules 或组件框架；保留 CSS tokens 和 SVG，可复用到桌面壳。多行程持久化需先扩展 schema 与迁移逻辑。

## 数据和隐私

本地存储键 xiaotu.workspace.v1 保存 profile、trip、plan、expenses、planMode。聊天只在页面内存；工具来源与地点列表也仅在页面内存，刷新后提示无查询记录。暂无登录与多设备同步。

发送消息时，旅行上下文、最近 12 条历史消息、可选画像与现有计划发送给同源后端。密钥不在浏览器输入或保存。模型、工具、用户、本地存储文本统一 HTML 转义，不执行响应中的 HTML。

限制：
- 配置存在不等于调用已验证；按 mode / sources 显示真实状态。
- 模型草案不是实时报价或预订凭证。
- 记账仅本地记录，未连接支付服务。
- ICS 是下载文件，不是线上日历 MCP。
- 未持久化聊天会话，无账户或云数据库。

## 扩展入口

- 语音 / 图片：composer、发送 payload、后端校验；明确权限、大小上限、隐私与模型能力。
- 流式输出：替换 sendMessage 的 JSON 解析，保留超时、终止、错误恢复。
- 地图视图：itinerary 新增组件，只使用后端校验坐标，不暴露服务私钥。
- 画像版本与来源：新增 evidence / confidence / consentAt，保持建议→确认→保存。
- 多旅行：将单个 plan / trip / expenses 改为按 tripId 存储，增加 migration。
- 日历同步：calendarDialog 增加 OAuth、幂等键、写入审计，不复用“下载成功”文案。
- 预算再规划：现有调整仅改变上限；后续经用户确认再重规划，不能静默修改行程。
- 主题迁移：CSS 自定义属性为入口，支持 WebView 与 safe area。

## 验证边界

实现包含语义化标签、键盘焦点、中文输入法保护、reduced-motion、错误恢复、停止生成、敏感操作确认。具体自动检查与浏览器验收由主线汇总。没有浏览器截图记录时，不把代码检查称为视觉验收。评审页提供测试尺寸，未声称运行上游完整审计脚本或通过商标检索。
